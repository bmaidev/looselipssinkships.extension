# Engineering smoke evidence — 17 October 2026

Status: exploratory screening, not a release decision.

This scorecard records the first common-corpus run of 11 model candidates plus the two production baselines. Thresholds were selected on 110 deterministic calibration records and the table reports the separate 390-record held-out partition. The smoke and full corpora share a generator and seed and can share texts, so full-corpus expansion remains exploratory. Confirmatory conclusions require an independently authored holdout or a separately governed external test split.

Corpus SHA-256: `d0c632ddbe09b635a3fa83e5b86588f85a3bd4a2e92574b44507037e0257bbc9`

Reference system: Apple arm64, macOS 26.2, 10 logical CPUs, Python 3.13.0, Node 25.2.1. Latency and RSS compare these desktop adapters; they are not substitutes for Chrome/Edge WebGPU measurements.

## Sensitive-information coverage

The compact leader remains poor on contextual sensitive information. Family character recall for Masker Mini was 11.8% for belief/association, 4.4% for financial sensitivity, 0.9% for health sensitivity, 0% for legal sensitivity, 5.8% for sexual-orientation/personal sensitivity, and 7.3% for safeguarding/child status.

NVIDIA GLiNER materially raises those families—to 79.3%, 58.8%, 80.4%, 78.5%, 97.1%, and 51.3% respectively—but still misses too much and is far outside the extension resource envelope. This is the clearest evidence that the next engineering direction should be targeted compact sensitive-information heads or distillation, not simply a lower threshold on a generic PII model.

## Screened and deferred candidates

- DataFog PII EN 71M: screened out because the pinned repository declares a custom architecture without the executable implementation required for a reproducible run.
- Desert Ant Redact: screened out pending licence review and a dedicated LiteRT adapter. The current distribution is source-available, and unsafe PyTorch deserialisation is prohibited.
- Perplexity PII Masking: remote custom code and approximately 0.6B parameters; research-only and outside the resource envelope.
- Knowledgator Small, Vicgalle Small, Gretel Bi Small, and OpenMed Nemotron v2: deferred after the edge/broad controls established that their larger native runtimes cannot satisfy the default browser budget. They remain catalogued for future distilled/quantized artifact work.

## Engineering findings

1. No candidate or ensemble meets the preregistered safety gates. No model should be shipped as a claim of complete PII/PSI protection.
2. Masker Mini is the current compact Pareto candidate, not the final answer.
3. Broad open-label models can find contextual PSI, but current memory and latency are unacceptable and over-redaction is threshold-sensitive.
4. Generic NER is not a substitute for PII-specific training.
5. Rules remain valuable for Australian structured identifiers, but the shipped rules and name heuristic need their own false-positive and corruption improvements.
6. A likely production architecture is rules + a compact PII token classifier + one or more distilled contextual PSI heads, with category-specific thresholds and explicit uncertainty/fail-safe UX.

## Integrity checks completed

- Dependency-free harness tests cover exact offsets, byte reproducibility, checksum enforcement, stable disjoint partitions, confidence filtering, calibration constraints, production-detector execution, threshold-aware ensembles, and specialist curriculum isolation.
- Candidate revisions are immutable commit hashes.
- Remote custom code is disabled by default.
- Hugging Face token models require safetensors; ONNX is loaded as data; GLiNER evaluation is refused unless the installed loader visibly enforces `weights_only=True`.
- Presidio public-suffix validation is forced to its bundled offline snapshot.
- Root and benchmark npm audits report zero known vulnerabilities as of the run date. `pip-audit 2.10.1` reports no known vulnerability in the isolated Python environment after upgrading pip to 26.2.1; the direct spaCy language-model wheel is not indexed by PyPI, so its published SHA-256 is pinned separately in the environment snapshot.
