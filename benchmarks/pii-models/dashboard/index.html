    Transparent reporting is not independent validation.

    This dashboard is generated from retained aggregate artifacts. It does not create new experiments, establish independence, certify safety, prove source authenticity, or replace scientific/security review.

    What is measured

    Risk-weighted character recall
    Captured sensitive characters, weighted by the fixed taxonomy risk, divided by all weighted gold sensitive characters. Partial spans still leak.
    Full-document protection
    Positive documents where every gold sensitive character is covered. Negative documents are excluded from this denominator.
    Clean negatives
    Gold-negative documents left completely untouched. A tiny false positive still makes a document unclean.
    Over-redaction
    Non-sensitive characters masked, divided by all non-sensitive characters. Low over-redaction alone can hide poor document-level usability.

    Interpretation rules

    • Do not pool different dataset hashes, partitions, schemes or study designs.
    • Calibration-selected primary thresholds are separate from fixed, permissive diagnostics. Historical thresholds predate the newer utility objective.
    • Report retained failures, zeros and missing evidence. No cross-corpus winner is declared.
    • Use reported paired source/text-cluster bootstrap differences for comparisons. Shared authorship or source dependence can remain.
    • Viewed holdouts are regression data for later tuning. A local locked plan is not an independently registered protocol.
    • Older artifacts lack some intervals and support counts. They remain missing; the dashboard does not reconstruct them from correlated rows.

    Release standard, not a progress percentage

    Lower 95% bounds: weighted recall ≥99.5%, highest-risk family recall ≥99%, full-document protection ≥98%, clean negatives ≥98%. Upper over-redaction bound ≤2%. Also require cluster support, independent human-reviewed data, artifact integrity, redistribution review and exact offline Chrome/Edge package tests.

    Reference-device warm p95 ≤50 ms, cold start ≤2 s, complete default download ≤100 MB and whole-extension peak memory ≤512 MiB. A Node/WASM run cannot pass browser gates.
