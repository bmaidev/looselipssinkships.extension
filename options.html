Submit & Upload Guard

Intercept form submissions and file uploads to ensure PII is redacted before data leaves the page.

Reversible Tokenization

Replace PII with unique, numbered tokens ([[EMAIL_1]], [[PERSON_1]]) instead of generic masks, so the AI can reason over consistent placeholders. The token↔value mapping is memory-only and original values are never restored into the website's DOM. Experimental. When off, PII is masked irreversibly (the safer default).

Voice Dictation Detection

Detects potential dictation bypass paths: microphone capture packaged for later use, and speech recognition not explicitly marked local. This is a risk signal, not proof of upload. Detection is observe-only and records no audio.

Document Processing

Enable file upload buttons alongside text redaction. Supports Word (.docx), Excel (.xlsx), HTML, Markdown, PDF, and images. PDF/image redaction uses local OCR (requires vendor setup) or an optional OCR container.
